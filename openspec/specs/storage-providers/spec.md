# storage-providers

## Requirements

### Requirement: Абстракция хранилища
Система SHALL работать с внешними хранилищами через единый контракт `StorageProvider`, не завися от их специфики, и SHALL поддерживать несколько провайдеров.

#### Scenario: Список содержимого
- **WHEN** пользователь открывает хранилище
- **THEN** система показывает папки и файлы с метаданными (имя, размер, признак папки)

#### Scenario: Непрозрачные ссылки
- **WHEN** провайдер идентифицирует объекты по своим правилам
- **THEN** остальная система работает с непрозрачным `sourceRef` и не знает деталей провайдера

### Requirement: Подключение WebDAV
Система SHALL позволять подключить WebDAV-хранилище по URL, логину и паролю, и SHALL сохранять подключение между запусками.

#### Scenario: Успешное подключение
- **WHEN** пользователь вводит URL, логин и корректный пароль приложения
- **THEN** хранилище подключается, содержимое доступно

#### Scenario: Неверный пароль
- **WHEN** сервер отвечает ошибкой авторизации
- **THEN** система сообщает о неверных учётных данных и предлагает проверить пароль приложения

#### Scenario: Отключение
- **WHEN** пользователь отключает хранилище
- **THEN** сохранённые учётные данные удаляются, импортированные книги остаются в библиотеке

### Requirement: Импорт книги из хранилища
Система SHALL импортировать книгу из удалённой папки так же, как из локальной: фильтр аудио, естественная сортировка, длительности и метаданные.

#### Scenario: Импорт удалённой папки
- **WHEN** пользователь выбирает папку с аудио на сервере
- **THEN** создаётся книга со списком треков, упорядоченных естественным порядком

#### Scenario: Длительность удалённого трека
- **WHEN** длительность трека недоступна удалённо
- **THEN** система уточняет её при воспроизведении, не блокируя импорт

### Requirement: Воспроизведение удалённых треков
Система SHALL воспроизводить удалённый трек из локального кэша, если он скачан, иначе — потоково из хранилища.

#### Scenario: Потоковое воспроизведение
- **WHEN** трек не скачан и есть сеть
- **THEN** воспроизведение идёт потоково с поддержкой перемотки (Range)

#### Scenario: Нет сети и нет кэша
- **WHEN** трек не скачан и сети нет
- **THEN** система сообщает о необходимости сети для этого трека

### Requirement: Офлайн-кэш
Система SHALL позволять скачивать книгу для офлайн-прослушивания и SHALL управлять размером кэша.

#### Scenario: Скачивание книги
- **WHEN** пользователь включает «Доступно офлайн» для книги
- **THEN** треки скачиваются с индикацией прогресса, после чего книга играет без сети

#### Scenario: Очистка
- **WHEN** пользователь очищает кэш книги
- **THEN** локальные копии удаляются, а записи книги и треков в библиотеке остаются

#### Scenario: Лимит размера
- **WHEN** кэш превышает заданный лимит
- **THEN** система вытесняет давно не использованные треки

### Requirement: Обработка ошибок провайдера
Система SHALL различать сетевые ошибки и ошибки авторизации и SHALL показывать понятные сообщения.

#### Scenario: Потеря авторизации
- **WHEN** сервер возвращает ошибку авторизации при обращении
- **THEN** система предлагает повторно ввести учётные данные и не теряет импортированные книги
