# Player Book

Android-приложение для прослушивания аудиокниг. Монорепозиторий: `mobile/` — Flutter-приложение, `server/` — будущая серверная часть.

## Purpose

Дать пользователю ощущение единой непрерывной аудиокниги, даже если физически книга состоит из множества файлов в папке. Плеер помнит место прослушивания неограниченно долго, умеет мягко засыпать по таймеру и работает как с локальными файлами, так и с внешними хранилищами (начиная с Google Drive).

## Tech Stack

### Mobile (`mobile/`)
- **Flutter** (Dart) — Android сейчас, iOS в перспективе.
- **just_audio** — воспроизведение, плейлисты, gapless.
- **just_audio_background** (обёртка над `audio_service`) — фоновое воспроизведение, media notification, lock screen, Android Auto, foreground service.
- **riverpod** — управление состоянием.
- **go_router** — навигация.
- **drift** (SQLite) — библиотека, позиции, кэш-индекс.
- **sensors_plus** — детект встряхивания для sleep timer.
- **google_sign_in** + **googleapis** — Google Drive.
- **minio** / **webdav_client** — будущие S3 / WebDAV-провайдеры.

### Server (`server/`) — фаза 4, стек не зафиксирован
- Кандидаты: Dart (serverpod), Kotlin/Ktor, Go.
- БД: PostgreSQL. Файлы: объектное хранилище (S3/MinIO).
- До реализации фиксируется только Api-контракт.

## Architecture

- Feature-first структура: `mobile/lib/features/<feature>/`.
- Слои внутри фичи: `presentation` (виджеты, контроллеры), `domain` (модели, use cases), `data` (репозитории, источники).
- Внешние хранилища — за абстракцией `StorageProvider`; реализация выбирается конфигом. Первая реализация — Google Drive.
- Воспроизведение идёт через единый плеер-сервис поверх `just_audio`, наружу отдаёт единый таймлайн книги.

## Project Conventions

- Язык общения и документации — русский; идентификаторы в коде — английский.
- Спеки — источник правды. Поведение меняется через change proposal в `openspec/changes/`, затем архивируется в `openspec/specs/`.
- Комментарии в коде не пишем без необходимости; самодокументируемые имена.
- Публичное поведение покрываем тестами (unit для domain/data, widget для UI).

## Domain Context

- **Book (Книга)** — папка с аудиофайлами. Пользователь видит её как один объект.
- **Track (Файл)** — отдельный аудиофайл внутри книги. Пользователю не показывается.
- **Total timeline** — суммарная длительность всех треков книги; единственная шкала, которую видит пользователь.
- **Resume position** — пара (`trackIndex`, `offsetMs`), место остановки. Хранится бессрочно.
- **Sleep timer** — таймер засыпания: по истечении громкость плавно уходит в ноль и воспроизведение ставится на паузу.
- **Storage provider** — абстрактный источник аудиофайлов (Google Drive, S3, WebDAV, локальная ФС).
- **Offline cache** — локальная копия треков из внешнего хранилища для прослушивания без сети.
