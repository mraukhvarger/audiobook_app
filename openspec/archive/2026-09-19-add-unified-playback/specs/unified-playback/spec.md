# unified-playback — Spec Delta

## ADDED Requirements

### Requirement: Единый поток
Система SHALL воспроизводить все треки книги как один непрерывный поток и SHALL представлять пользователю единый таймлайн.

#### Scenario: Запуск книги
- **WHEN** пользователь нажимает «Слушать» на книге
- **THEN** воспроизведение начинается с первого трека и продолжается по всем трекам без ручного вмешательства

### Requirement: Общая шкала времени
Система SHALL показывать позицию и общую длительность в терминах суммарного времени книги, а не отдельного файла.

#### Scenario: Отображение позиции
- **WHEN** книга из двух треков по 10 минут, проиграно 12 минут
- **THEN** шкала показывает 12 минут из 20

### Requirement: Перемотка через границы файлов
Система SHALL позволять перематывать на любую суммарную позицию, включая позиции в других файлах.

#### Scenario: Seek вперёд через файл
- **WHEN** пользователь перематывает на 15-ю минуту книги из двух треков по 10 минут
- **THEN** воспроизведение продолжается с 5-й минуты второго трека

#### Scenario: Seek назад через файл
- **WHEN** пользователь на 2-м треке перематывает в позицию до конца первого трека
- **THEN** воспроизведение продолжается в первом треке с нужной позиции

### Requirement: Непрерывный переход между треками
Система SHALL переходить между треками без заметного разрыва, если формат это позволяет.

#### Scenario: Конец трека
- **WHEN** текущий трек заканчивается
- **THEN** следующий трек продолжается с минимальной задержкой, суммарная шкала растёт непрерывно

### Requirement: Фоновое воспроизведение
Система SHALL продолжать воспроизведение при свёрнутом приложении и предоставлять управление через системное уведомление и экран блокировки.

#### Scenario: Сворачивание приложения
- **WHEN** пользователь сворачивает приложение во время воспроизведения
- **THEN** воспроизведение продолжается, а в уведомлении доступны play/pause и перемотка

#### Scenario: Управление с экрана блокировки
- **WHEN** экран заблокирован
- **THEN** пользователь может управлять воспроизведением с экрана блокировки

### Requirement: Устойчивость к ошибке трека
Система SHALL NOT прерывать воспроизведение всей книги из-за ошибки одного трека.

#### Scenario: Битый файл
- **WHEN** один из треков не может быть воспроизведён
- **THEN** система сообщает об ошибке и продолжает со следующего доступного трека
