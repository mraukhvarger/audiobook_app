# Change: add-storage-providers

## Why
Аудиокниги часто хранятся в облаке. Нужен единый способ подключать разные хранилища и слушать книги оттуда, начиная с Google Drive. Архитектура должна позволять позже добавить S3, WebDAV, Яндекс.Диск и собственный сервер без переписывания плеера.

## What Changes
- Абстракция `StorageProvider` с единым контрактом: аутентификация, список папок/файлов, метаданные, потоковое чтение, скачивание. (Вводится change'ом `add-webdav-storage`; здесь используется.)
- Первая реализация — **Google Drive** (OAuth 2.0, `drive.readonly`).
- Импорт книги из провайдера так же, как из локальной папки (`book-library`).
- **Офлайн-кэш**: скачивание треков книги на устройство, воспроизведение из кэша, очистка кэша, управление лимитом.
- Стратегия воспроизведения: из кэша, если есть; иначе — потоково из облака (если поддерживается) либо скачивание по требованию.
- UI: экран подключения хранилища, список книг из облака, статус загрузки/кэша.

## Impact
- Новая capability: `storage-providers`.
- Зависит от `book-library` (импорт) и `unified-playback` (источники треков).
- Новые пакеты: `google_sign_in`, `googleapis`, `path_provider`.
- Требуется проект в Google Cloud Console и экран согласия OAuth (см. design.md).
