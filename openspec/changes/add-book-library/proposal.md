# Change: add-book-library

## Why
Пользователю нужен способ добавлять аудиокниги и видеть их как единые объекты, а не как наборы файлов. Без библиотеки нечего воспроизводить.

## What Changes
- Модель `Book`: папка с аудиофайлами + вычисляемые метаданные (название, список треков, суммарная длительность).
- Импорт книги: пользователь выбирает папку (дерево SAF на Android или папку провайдера хранилища).
- Сортировка треков: естественный порядок (natural sort) с учётом числовых префиксов (`01`, `02`, ... `10`), затем по имени.
- Вычисление суммарной длительности и длительности каждого трека.
- Экран библиотеки: список книг, обложка (если есть), прогресс прослушивания, длительность.
- Экран книги: оглавление (треки скрыты как отдельные сущности), кнопка «Слушать/Продолжить».
- Извлечение метаданных (название, автор, обложка) из файлов, с fallback на имя папки.
- Удаление книги из библиотеки (без удаления файлов).

## Impact
- Новая capability: `book-library`.
- Затрагивает: `mobile/lib/features/library/`, хранилище drift.
- Требует платформенных разрешений на чтение (SAF / MediaStore).
