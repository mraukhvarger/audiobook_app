# Change: add-unified-playback

## Why
Пользователь не должен видеть отдельные файлы. Нужен единый непрерывный поток с общей шкалой времени, плавными переходами между файлами и фоновым воспроизведением.

## What Changes
- Плеер-сервис поверх `just_audio`, собирающий треки книги в единую очередь (`ConcatenatingAudioSource`).
- Единый таймлайн: позиция и перемотка считаются в терминах суммарной длительности книги, а не отдельного файла.
- Перемотка через границу файлов (seek на суммарную позицию).
- Gapless-переход между файлами.
- Фоновое воспроизведение: media notification, управление с lock screen, продолжение при свёрнутом приложении.
- Управление: play/pause, перемотка вперёд/назад, переход к следующему/предыдущему файлу внутри книги.
- Обработка ошибок трека (битый/отсутствующий файл) без падения всей очереди.

## Impact
- Новая capability: `unified-playback`.
- Затрагивает: `mobile/lib/features/player/`, интеграция `just_audio_background`.
- Зависит от `book-library` (модели Book/Track).
- Android: foreground service и разрешение `POST_NOTIFICATIONS`.
